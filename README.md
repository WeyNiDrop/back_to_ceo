# Back To CEO · 重回巅峰之路

**简体中文** · [English](README.en.md)

一款以董事会席位争夺为核心的单人策略卡牌游戏。你扮演前任 CEO Gesen Yellow，从 0 席起步，在三场连战中夺回董事会的控制权。

[在线游玩](https://btceo.create-ai.cc/) · [完整玩法与开发文档](PROJECT_DOC.md) · [MIT License](LICENSE)

## 项目目的

游戏用虚构的董事会之争，把商战中的公关、资金运作与董事联盟做成可操作的卡牌机制。每回合都要决定是争席、加锁，还是留些资金和影响力给下一轮。项目开源，方便玩家和开发者阅读源码、调整卡牌或扩展对手策略。

游戏也通过分享文案和站外链接表达对黄仁勋回归 NVIDIA CEO 职位的支持。[Stand with Jensen](https://standwithjensen.com/)

## 玩法机制

每局从 11 位 Boss 中随机抽取 3 位依次挑战。每关有 9 个董事会席位，最多进行 6 回合。首次进入可选择简体中文或 English，随后查看新手教学。

### 通关条件

| 情况 | 判定 |
| --- | --- |
| 第 1 关即时胜利 | 控制至少 6 席 |
| 第 2、3 关即时胜利 | 控制至少 7 席 |
| 任意一关锁定胜利 | 锁定至少 5 个我方席位 |
| 第 6 回合结算 | 对手行动结束后，仍控制至少 5 席即可过关 |
| 提前失败 | 对手先锁定 5 席 |

连赢三关即通关。第 6 回合结束仍未达到席位门槛，或对手提前锁定多数席位，本局结束。

### 出牌与对手行动

1. **管理手牌。** 每关抽 4 张起始手牌。牌组有 21 张牌，来自 19 种卡牌，分为体力、影响力、间谍和政治四类。点击手牌出牌，按牌面支付体力、资金或影响力。卡牌词条可能改变费用和效果。
2. **控制董事会。** 卡牌和技能可以争取中立席位、夺取未锁定的敌方席位，或保护已有席位。锁定的席位会计入当前占席数，也能抵御争夺和动摇。
3. **预判反击。** 对手的基础出牌数与你本回合打出的卡牌数相同，基础至少 2 张。减牌效果在此基础上最多扣 2 张。对手随后结算 Boss 被动，「700人联名逼宫」可以跳过这次被动。点击牌桌上的被动名称可查看详细效果。
4. **延续优势。** 每回合可以换 1 张手牌。新回合体力回满并摸 2 张，手牌上限为 5 张。过关后，下一关按规则继承部分资金和影响力，重新发牌并刷新技能次数。

### 英雄技能

三个主动技能每关各可用 2 次，同一技能每回合限用 1 次。

| 技能 | 效果 |
| --- | --- |
| 皮衣直播 | 消耗 2 点体力，获得 20 点影响力并摸 1 张牌 |
| 股权加锁 | 消耗 1 点体力，永久锁定 1 个未锁定的我方席位 |
| 舆论号召 | 消耗 15 点影响力，优先取得中立席位，其次夺取未锁定敌席 |
| 皮衣光环（被动） | 每回合首次打出影响力牌时，额外获得 5 点影响力 |

## 项目架构

项目使用原生 HTML、CSS 和 JavaScript。浏览器负责游戏状态、渲染、对手策略与音效，生产环境通过 Cloudflare Pages 托管静态文件。

| 模块 | 职责 |
| --- | --- |
| [`index.html`](index.html)、[`style.css`](style.css) | 牌桌、手牌、首次教学、胜负结算、分享弹窗和响应式布局 |
| [`game.js`](game.js) | 卡牌、资源、行动结算、三关连战和 X 分享链接 |
| [`ai.js`](ai.js) | 席位初始化、Boss 被动、内置对手策略和可选的大模型对手 |
| [`i18n.js`](i18n.js) | 中英文文案、语言切换和资金显示格式 |
| [`sound.js`](sound.js) | 使用 Web Audio API 合成游戏音效 |
| [`assets/`](assets/) | 角色头像、卡牌与结局插画、字体和分享海报 |
| [`scripts/`](scripts/) | 打包静态文件，生成正式分享链接及大图卡片标签 |

标准对手在浏览器中运行，可以直接开玩。「对手设置」支持接入兼容 OpenAI Chat Completions 的接口。语言、教学状态及对手配置由浏览器保存。使用自定义模型时，浏览器会把请求和 API Key 发送给所配置的接口。

## 本地运行与部署

克隆仓库后启动静态服务器，然后打开 [本地游戏](http://127.0.0.1:8080/)。

```sh
git clone https://github.com/WeyNiDrop/back_to_ceo.git
cd back_to_ceo
python3 -m http.server 8080 --bind 127.0.0.1
```

用 Node.js 22 可以生成部署产物。

```sh
node scripts/build-frontend.mjs
```

Cloudflare Pages 从 GitHub 的 `main` 分支构建，使用上述命令，发布 `dist/`。生产构建会把正式域名写入分享标签。自托管时可用构建变量 `PUBLIC_SITE_URL` 指定公开地址。更多配置见[前端部署文档](PROJECT_DOC.md#10-前端部署)。
